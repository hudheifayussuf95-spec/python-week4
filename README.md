
# Week 4 Assignment: Hands-On Lab - Grades, Eligibility & Smart Decisions

## Assignment Files

- welcome.py: Creates a welcome() function that returns greeting messages for different names.

- toolbox.py: Contains three functions: double(), is_pass(), and greet(), demonstrating parameters, return values, and default arguments.

## Reflection

The hardest function to write was greet() because it uses a default parameter. I learned that a function can use a default greeting when no custom greeting is provided, but it can also accept a different greeting.
